# Lore Tidy

ส่วนขยายของ SillyTavern สำหรับจัดระเบียบ lorebook ใช้ดูว่าแต่ละเล่มถูกใช้ที่ไหน หาเล่มที่ไม่มีใครใช้แล้ว และลบทีละหลายเล่มได้ โดยดาวน์โหลดไฟล์สำรองให้ก่อนลบ

เหมาะกับกรณีที่การ์ดบางใบมาพร้อม lorebook หลายเล่ม พอลบการ์ดทิ้ง lorebook ยังค้างอยู่ จนรายการยาวขึ้นเรื่อยๆ

## ติดตั้ง

Extensions → Install extension → วาง URL ของ repo นี้

ทดสอบกับ SillyTavern 1.19.0

## เปิดใช้

- ปุ่มไม้กวาด 🧹 ในแผง World Info อยู่ถัดจากปุ่ม Import
- หรือพิมพ์ `/loretidy`
- หรือไปที่ Extensions → Lore Tidy → เปิด Lore Tidy

ตอนเปิด ส่วนขยายจะเช็ค Chat Lore ในแชทของทุกการ์ดให้เอง ระหว่างนั้นจะลบไม่ได้ เพราะยังไม่รู้ว่าเล่มไหนผูกกับแชทอยู่บ้าง

## ในแผง World Info

**ชื่อเล่ม Global** บนมือถือ ช่อง Active World(s) for all chats ขึ้นแค่ว่า "2 Items" Lore Tidy จะแสดงชื่อเล่มที่เปิดเป็น Global ไว้ใต้ช่องให้เห็นเลย แตะชื่อเพื่อเปิดในตัวแก้ไข แตะ ✕ เพื่อถอดออกจาก Global บนคอมช่องนี้แสดงชื่ออยู่แล้ว จึงไม่แสดงซ้ำ

**Active World(s) for this chat** แสดงทุกเล่มที่ใช้กับแชทที่เปิดอยู่นอกจาก Global
- 💬 Chat Lore ของแชทนี้ แตะ ✕ เพื่อเลิกผูก
- 👤 เล่มหลักและเล่มเสริมของการ์ด ถ้าเป็นแชทกลุ่มจะแสดงของทุกตัวละครในกลุ่ม พร้อมชื่อตัวละคร
- 🎭 เล่มของ persona ที่ใช้อยู่
- ปุ่มข้างหัวข้อใช้ผูกหรือเปลี่ยน Chat Lore ของแชทนี้
- เล่มที่ถูกลบไปแล้วแต่ยังมีลิงก์ค้างอยู่จะขีดฆ่าไว้
- ถ้าแชทนี้เคยผูกเล่มผ่าน WorldInfoPlus จะมีบรรทัดบอกไว้ พร้อมทางลัดไปย้ายใน Lore Tidy

ปิดทั้งสองส่วนนี้ได้ที่ Extensions → Lore Tidy

## แต่ละแท็บ

**ไม่มีใครใช้** คือเล่มที่ไม่ได้เป็นเล่มหลักหรือเล่มเสริมของการ์ดไหน ไม่ได้ผูกกับ persona ไม่ได้เปิดใน Global และไม่ได้เป็น Chat Lore ของแชทไหน ส่วนใหญ่คือเล่มที่เหลือจากการ์ดที่ลบไปแล้ว

**ตามการ์ด** จัดกลุ่มเล่มตามการ์ดที่ใช้ มีรูปการ์ดกำกับ เล่มไหนเป็นเล่มหลัก เล่มเสริม หรือ Chat Lore จะบอกไว้ข้างชื่อ ติ๊กที่หัวกลุ่มเพื่อเลือกทุกเล่มของการ์ดนั้น เล่มที่ไม่ผูกกับการ์ดไหนจะรวมอยู่กลุ่มสุดท้าย

**ทั้งหมด** แสดงทุกเล่ม พร้อมป้ายบอกว่าใช้ที่ไหน
- 🌐 Global: เปิดไว้ใน Global World Info
- 👤 เล่มหลัก / เล่มเสริม: การ์ดที่ใช้เล่มนี้
- 🎭 Persona: persona ที่ผูกเล่มนี้
- 💬 Chat Lore: จำนวนแชทที่ผูกเล่มนี้ ชี้เมาส์เพื่อดูว่าแชทไหน หรือดูในแท็บตามการ์ด
- 🧩 WIP: แชทที่เคยผูกเล่มนี้ผ่าน WorldInfoPlus

**ลิงก์ค้าง** เก็บกวาดข้อมูลที่ชี้ไปยังของที่ไม่มีแล้ว
- การ์ดที่ชี้ไปยังเล่มที่ถูกลบไปแล้ว ถ้าเป็นเล่มเสริมจะถอดลิงก์จากตรงนี้ได้เลย
- รายการเล่มเสริมของการ์ดที่ลบไปแล้ว ตอนลบการ์ด SillyTavern ไม่ได้ลบรายการนี้ในการตั้งค่า ล้างได้โดยไม่กระทบตัว lorebook
- ข้อมูลที่ WorldInfoPlus ทิ้งไว้ (ดูหัวข้อถัดไป)

ช่องค้นหาด้านบนหาได้ทั้งชื่อเล่มและชื่อการ์ด

## ลบและสำรอง

1. ติ๊กเล่มที่จะลบ
2. กด **ลบ** แล้วตรวจรายชื่อ ถ้ามีเล่มที่ยังมีคนใช้อยู่จะมีคำเตือนขึ้น
3. ตัวเลือก **ดาวน์โหลดไฟล์สำรอง (.zip) ก่อนลบ** ติ๊กไว้ให้ตั้งแต่แรก ถ้าอ่านเล่มไหนจากเซิร์ฟเวอร์ไม่ได้ จะยกเลิกทั้งหมดโดยยังไม่ลบอะไร

ใน .zip มีไฟล์ .json แยกเล่ม ถ้าอยากเอาเล่มไหนกลับมา ให้แตกไฟล์แล้วใช้ปุ่ม Import ในแผง World Info ได้ตามปกติ ปุ่ม **สำรอง** ใช้ดาวน์โหลดเล่มที่เลือกโดยไม่ลบก็ได้

ตอนลบ Lore Tidy จะถอดชื่อเล่มนั้นออกจากรายการเล่มเสริมของทุกการ์ดให้ด้วย

## ย้ายออกจาก WorldInfoPlus

WorldInfoPlus เก็บการผูก Multi Chat Lore ไว้ในการตั้งค่าของตัวเอง และล้างช่อง Chat Lore ของ SillyTavern ทิ้ง ถอน WorldInfoPlus แล้วข้อมูลนั้นยังอยู่ในการตั้งค่า Lore Tidy อ่านข้อมูลนั้นมาใช้ได้ดังนี้

- เล่มที่ผูกกับแชทผ่าน WorldInfoPlus จะไม่ถูกนับเป็นเล่มที่ไม่มีใครใช้
- แท็บ **ลิงก์ค้าง** มีรายการเล่มที่ WorldInfoPlus เปิดค้างไว้ใน Global กดถอดออกได้ในครั้งเดียว
- เปิดแชทที่เคยผูกไว้ แล้วมาที่แท็บ **ลิงก์ค้าง** จะเลือกเล่มแล้วผูกเป็น Chat Lore ของ SillyTavern ได้ Chat Lore ของ SillyTavern ผูกได้แชทละ 1 เล่ม ถ้าแชทนั้นเคยผูกหลายเล่ม ให้เพิ่มเล่มที่เหลือเป็นเล่มเสริมของการ์ดแทน
- ย้ายครบแล้ว กด **ล้างข้อมูล WIP ทั้งหมด** ได้

## ข้อจำกัด

- ไม่ได้เช็คแชทกลุ่ม ถ้าผูก Chat Lore ไว้ในแชทกลุ่ม เล่มนั้นอาจขึ้นว่าไม่มีใครใช้ ให้ดูให้ดีก่อนลบ
- การเช็คแชทต้องให้เซิร์ฟเวอร์อ่านไฟล์แชททุกไฟล์ ถ้ามีการ์ดหรือแชทเยอะมาก (โดยเฉพาะบนมือถือ) อาจใช้เวลาสักพัก ผลเช็คจะเก็บไว้จนกว่าจะเปลี่ยนแชทหรือแก้การ์ด แล้วจะเช็คใหม่ตอนเปิดครั้งถัดไป
- entry ที่อยู่ในการ์ดเอง (embedded lorebook) ไม่นับ เพราะไม่ใช่ไฟล์ lorebook แยก

## ข้อมูลเก็บไว้ที่ไหน

Lore Tidy ไม่เก็บข้อมูลของตัวเอง ทุกอย่างอ่านจากการตั้งค่าและไฟล์ของ SillyTavern ตอนเปิด สิ่งที่ถูกเขียนมีแค่สิ่งที่คุณกดเอง ได้แก่ ลบเล่ม ถอดลิงก์ ถอดออกจาก Global และผูก Chat Lore
